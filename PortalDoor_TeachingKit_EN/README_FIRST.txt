Portal Door Teaching Kit | 8th Wall Desktop (open source) interactive-art course
=================================================================================

Audience : digital media students (no coding required)
Duration : 8 hours (4 units x 2 hours)

QUICK START FOR STUDENTS
1. Create a new blank project in 8th Wall Desktop.
2. Copy everything inside "01_Add_to_your_project/src/" into your project's src folder.
3. In the Inspector: set the Camera to World -> add an Empty object -> Add Component -> portal-door.
   Everything else is set in the Inspector. See "02_Student_Handouts/Student_Guide.pdf".

CONTENTS
01_Add_to_your_project   portal-door.ts (the component) + a sample panorama
02_Student_Handouts      Student Guide, Inspector Quick Reference, Project Planning Sheet (printable)
03_Instructor            8-hour lesson plan, metaphors for the principle, "under the hood"
                         notes, assessment, troubleshooting
04_Editable_Sources      Markdown sources of every handout, for editing or adding screenshots
05_Assets                360 panorama drawing template (4096x2048), two sample sounds

NOTES FOR INSTRUCTORS
* Before class, run through the Student Guide in a brand-new blank project and add screenshots
  from your version of 8th Wall Desktop.
* Phones need an https link to use the camera. See "Preparation" in the Instructor Handbook.
* Built and tested with 8th Wall ECS 3.2.1.
